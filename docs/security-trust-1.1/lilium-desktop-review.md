## Revisão focal
- desktop/launcher.py: reserva socket 127.0.0.1 em porta dinâmica, sem proxy headers; cria token de sessão e abre browser local. SQLite sob LOCALAPPDATA. Diagnósticos usam arquivo temporário e fixture fictícia; não constituem teste do antivírus.
- core/api.py, session.py: checagem de Host, token aleatório de 256 bits, comparação constante, Origin e Fetch Metadata, CSP e no-store. Modo de desenvolvimento importado diretamente permanece sem token; não usar como serviço público. Token de sessão é sensível e confere acesso à API local, não existe isolamento multiusuário.
- imports.py, metrics.py: limites de entrada e linhas, validação de datas/centavos, XLSX com limite de tamanho expandido e partes, recusa fórmulas, macros e links externos. Não é sandbox completa contra arquivos hostis.
- store.py, backup.py: SQL parametrizado, validação do agregado, limite de 200 registros, merge sem sobrescrita e rollback transacional. Banco e exportações não criptografados pelo app; secure_delete não prova apagamento forense.
- JS empacotado: inspeção ampla de APIs exportadas, sintaxe e pontos de rede/armazenamento. Connect é intercâmbio local de dados, não IA remota; Copilot é baseado em regras. workspace.js utiliza fetch relativo para API local e sessionStorage para token. Revisão anterior focal e browser CI não demonstram ausência absoluta de tráfego ou XSS.
- build_windows.py, setup_env.py, BAT e release_manager.py: Python 3.12 x64, PyInstaller onedir 6.16.0, Pillow 13.0.0; dependências diretas fastapi 0.165.0, starlette 1.10.0, uvicorn 0.48.0, httpx 0.28.1, openpyxl 3.1.5, defusedxml 0.7.1. Setup/repair de fonte pode instalar dependências da rede; pacote portátil não requer execução desses scripts. Release manager verifica SHA-256, manifesto, nomes Windows e extração em pasta nova; não substitui versão anterior. Dependências transitivas resolvidas registradas no artefato; não há lock completo com hashes.
- Bundle contém Python312.dll, OpenSSL, SQLite, bibliotecas Microsoft, PIL e pydantic_core. Não houve análise de CVEs/licenças nativas, verificação de assinatura Windows ou revisão manual linha a linha de todos os JS e bibliotecas de terceiros. Auditoria parcial, não certificação.
