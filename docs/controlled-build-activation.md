# Controlled build activation / Ativação controlada
No build authorized by this change. Merge into the isolated target branch does not trigger compilation. Only a later single-parent commit changing exclusively validation/candidate-authorization.json activates this workflow. The file must bind source_commit to its exact parent SHA and include the following JSON keys: schema=1, owner_authorized_build=true, owner_reviewed_terms=true, microsoft_entitlement_reviewed=true, controlled_retention_authorized=true, release_approved=false. These flags record owner review, not independently verified legal or scan clearance. Never create the file before explicit owner confirmation and relevant license evidence. Do not put private documents, personal information or secrets in this public repository. Preserve original AV requirements and verify signed definitions <=24h before build. No public release authorization. Lilium workflow retains evidence only; exact binary handoff still needs full scans and private retention arrangement. Do not trigger it solely to discard another candidate. GitHub dispatch is not assumed available for workflows absent from main. Do not edit main merely to enable it.
