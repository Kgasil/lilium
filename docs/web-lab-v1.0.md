# Project Lilium — Web Lab 1.0

**25 de novembro de 2026 · Edição pública demonstrativa / Public demonstration edition**

## Português
A K&G Vision apresenta o Lilium Web Lab 1.0: a primeira edição pública do laboratório de inteligência empresarial do Project Lilium. Experimente indicadores de receita, custos e margem, formação de preços, ponto de equilíbrio, cinco cenários empresariais fictícios e projeções estatísticas diretamente no navegador, sem instalar o Desktop.

[Experimentar laboratório](https://kgasil.github.io/lilium/#lab) · [Insights CSV](https://kgasil.github.io/lilium/demo.html) · [Enviar feedback](https://github.com/Kgasil/lilium/issues/new?template=web-lab-feedback.md).

O laboratório destina-se a exercícios com dados fictícios. Não é um SaaS empresarial, sistema contábil, serviço comercial ou IA conectada. A versão 1.0 refere-se exclusivamente ao laboratório web; o Workspace Desktop permanece na prévia v0.14.0, sem assinatura digital, com aceitação manual detalhada e revisão de segurança/acessibilidade pendentes. O proprietário informou ter testado o aplicativo, mas não registrou os resultados dos casos. Não distribuir o Desktop como V1.0, nem utilizar dados reais.

## English
K&G Vision introduces Lilium Web Lab 1.0, the first public demonstration edition of its business intelligence lab. Explore revenue, costs and margins, pricing, break-even, five synthetic business scenarios and statistical forecasts directly in the browser. No Desktop installation is required.

The lab is for synthetic exercises only, not a commercial service, production SaaS, accounting system or connected AI. Version 1.0 applies solely to the public web lab. The unsigned Windows Desktop remains v0.14.0; detailed manual acceptance and security/accessibility review are open. The owner reported testing the application, without documented case outcomes. Do not distribute Desktop as V1.0 or use real data.

## Validation / Validação
The [public lab workflow](https://github.com/Kgasil/lilium/actions/runs/45722416065) passed calculation/DOM checks and Chromium acceptance for the earlier lab implementation.
